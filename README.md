## 💡 开发背景

我曾经是一名普通的跑步爱好者。因为训练不当，我经常受伤——膝盖疼、脚踝扭、肌肉拉伤……这些痛苦让我一次次被迫停下脚步。

后来，我开始自学运动科学、康复训练、跑步姿势等知识。我逐渐明白：**受伤不是运动的代价，而是方法的问题**。

我想把这些知识分享给更多和我一样的普通跑者，但我不会编程。

于是，我用小米 MiMo 大模型 + Vibe Coding 的方式，一点一点"对话"出了这个小程序。从零开始，历时数月，终于有了现在的样子。

**我希望它能帮助每一位新手跑者和徒步者，无伤、快乐地运动下去。**

## 🏃‍♂️ 功能模块

小程序分为两个核心世界：

### 🥾 徒步世界

专为陕西地区户外徒步爱好者打造，聚焦秦岭及周边经典路线。

**核心功能：**

| 功能 | 说明 |
|------|------|
| 📍 路线查询 | 秦岭及周边100+条经典徒步路线，含详细轨迹、海拔、里程 |
| 🏷️ 智能筛选 | 按难度、时长、季节、景观（红叶/草甸/瀑布/古迹）筛选 |
| ❤️ 收藏功能 | 收藏心仪路线，方便后续查看 |
| 📝 纠错反馈 | 发现路线信息有误？一键提交纠错 |
| 📊 用户等级 | 根据活动量提升等级，解锁更多权益 |
| 📢 安全提示 | 每条路线附带安全风险提示，倡导合法合规出行 |

**设计理念：**

- 安全第一：每条路线都标注风险等级和注意事项
- 合法合规：不鼓励穿越禁区，宣传相关法律法规
- 无痕山林：倡导环保理念，保护秦岭生态

---

### 🏃 跑步世界

面向跑步新手，提供科学训练和伤病预防知识。

**核心功能：**

| 功能 | 说明 |
|------|------|
| 📚 科普文章 | 跑步姿势、训练计划、伤病预防、装备选择等系列文章 |
| 🎯 分类阅读 | 按主题分类：跑前准备、跑中技巧、跑后恢复等 |
| 🔖 收藏与阅读 | 收藏文章、记录阅读历史、查看阅读统计 |
| 💭 阅读感受 | 为文章写下阅读感受，记录学习心得 |
| 📈 阅读统计 | 记录阅读数量、访问次数，见证成长 |

**内容体系：**

- 跑前：心理准备、装备选择、热身动作
- 跑中：呼吸节奏、步频步幅、姿势要领
- 跑后：拉伸恢复、伤病识别、营养补充

**文章来源：**

122篇精选科普文章，涵盖跑步新手需要的所有基础知识。

## 📁 项目结构

```
qinren-outdoor/
├── miniprogram/              # 小程序前端
│   ├── pages/                # 页面
│   │   ├── hiking-*/         # 徒步世界页面
│   │   ├── running-*/        # 跑步世界页面
│   │   └── profile/          # 个人中心
│   ├── components/           # 公共组件
│   ├── utils/                # 工具函数
│   ├── images/               # 图片资源
│   ├── towxml/               # Markdown渲染组件
│   ├── app.js                # 入口文件
│   ├── app.json              # 配置文件
│   └── app.wxss              # 全局样式
├── cloudfunctions/           # 云函数（未包含在仓库中）
├── project.config.json       # 项目配置
└── README.md                 # 本文件
```

> ⚠️ **注意**：出于安全考虑，`cloudfunctions/` 目录未包含在本仓库中。云函数代码包含数据库密钥等敏感信息，不适合公开。

## 🎯 设计理念

### 安全第一
- 每条徒步路线标注风险等级
- 提供天气预警和安全提示
- 宣传合法合规出行，不鼓励穿越禁区

### 无痕山林
- 倡导环保理念，保护秦岭生态
- 不乱扔垃圾，不破坏植被
- 只留下脚印，只带走照片

### 无伤运动
- 科学的训练方法，避免盲目训练
- 正确的跑步姿势，减少运动损伤
- 合理的恢复手段，持续健康运动
