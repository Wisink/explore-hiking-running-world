# 秦人户外集合

陕西户外徒步路线查询微信小程序

## 项目简介

「秦人户外集合」是面向陕西地区的户外徒步爱好者的一站式服务平台，聚焦于服务户外小白、新手、初级入门者、有一定户外经验但不追求高难度高风险路线的户外人，以及为宝爸宝妈提供周末亲子户外徒步路线查询功能。

## 核心理念

- 安全第一：每个功能模块都融入安全提示
- 合法合规：宣传法律法规，不鼓励违法穿越
- 环保出行：倡导「无痕山林」，保护自然环境

## 技术栈

- 前端：微信小程序原生开发
- 后端：微信云开发
- 数据库：云开发数据库
- 存储：云开发存储
- 版本管理：Git

## 开发规范

- 代码规范：ES6+，2空格缩进
- 命名规范：驼峰命名（变量/函数），短横线命名（文件/组件）
- 注释规范：关键逻辑必须注释
- 版本规范：功能完成打 Tag（v1.0, v1.1, v2.0...）

## 功能模块

- P0：首页+搜索+详情+欢迎页、登录+收藏+点赞、安全提示+合规标识
- P1：评论+纠错、用户等级系统、我的消息、法律法规、安全知识
- P2：后台管理、统计看板、无痕山林环保系统
- P3：海报生成+推送
